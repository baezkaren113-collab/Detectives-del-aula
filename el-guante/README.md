# El guante · La casa de las preguntas

Juego accesible para celular y computadora. Incluye seis escenarios de misterio y 15 estrellas que abren preguntas del cuento con tres opciones.

El archivo index.html incluye el código, las imágenes realistas y las tipografías. Se puede jugar con botones grandes, flechas del teclado, Tab y Enter, o selección por barrido. Ofrece letra ampliable, alto contraste, lectura con la voz del dispositivo, pistas, pausas y reintentos sin límite de tiempo.
