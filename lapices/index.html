CÓMO JUGAR

Compará los colores, el lugar y la dirección de las puntas. Usá las flechas para mover un lápiz y GIRAR para darlo vuelta. Después tocá COMPROBAR. Tenés ocho niveles. Los primeros mantienen el modelo visible; los últimos lo ocultan después de unos segundos para trabajar la memoria. Podés volver a verlo cuando lo necesites. No hay límite de tiempo para resolver. La pista te indica qué revisar.

También podés copiar el modelo con lápices reales sobre una mesa. La voz se activa con el botón superior y depende de las voces disponibles en tu dispositivo.
